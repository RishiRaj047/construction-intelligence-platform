# Construction Intelligence Platform

A Streamlit-based construction intelligence app for:

- PPE safety audits
- Crack and structural defect diagnostics
- Budget and valuation planning
- Site weather advisory and engineering Q&A

## Run locally

```bash
pip install streamlit pillow google-generativeai
streamlit run app.py
```

## Features

- AI-assisted site safety evaluation
- Demo and live Gemini modes
- Construction cost planning in INR
- Weather-aware site guidance
- Chat-based engineering assistant

## Notes

The app works in demo mode without a Gemini API key. To enable live analysis, add a valid API key in the sidebar.
